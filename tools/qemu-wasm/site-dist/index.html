PebbleOS Emulator

QEMU compiled to WebAssembly boots real PebbleOS firmware entirely in your browser, JIT-compiling ARM code to wasm. Paste an apps.repebble.com link below to install real apps onto the emulated watch.

Select a board and click Boot

Boot the watch first — then install apps from the store, upload a .pbw, or drag one onto the screen.
